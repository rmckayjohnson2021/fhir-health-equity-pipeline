# Healthcare Data Assumptions

This project uses synthetic data only.

It is not HIPAA-compliant production software and should not be used with real patient records.

Clinical examples are simplified to demonstrate data engineering patterns. Care-gap logic should be treated as illustrative, not medical advice or production clinical guidance.

Important modeling note:

- A1c is commonly represented as percent or mmol/mol.
- Blood glucose is a better example for mg/dL versus mmol/L unit conversion.
